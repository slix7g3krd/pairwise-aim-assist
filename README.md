# pairwise-aim-assist

手柄右摇杆轻推，准星在三个敌人之间来回粘，松开后又甩过头：瞄准辅助按屏幕距离选目标，没有考虑视野角和遮挡；吸附强度固定，不同灵敏度下手感不一致；目标切换没有滞后，两个敌人靠近时准星高频抖动；掩体后的敌人仍然被吸附，准星穿墙；辅助只对手柄生效，键鼠和触屏各有一套参数；网络延迟下目标位置用当前帧，吸附到残影；吸附区域是圆形，宽屏和超宽屏的横向范围不一致；目标优先级只看距离，忽略威胁度和队友标记；吸附时没有禁用垂直后坐力，压枪和辅助打架；目标死亡后吸附状态没释放，准星卡在尸体上；辅助强度随帧率变化，低帧率吸得更狠；多目标重叠时没有做软锁定，准星在两个头部之间跳；取消辅助后没有平滑回正，镜头突然弹开。gameplay/aim_assist.py 是核心，tests/test_aim_assist.py 15个红。要修的是：视野筛选；灵敏度归一；切换滞后；遮挡剔除；输入设备统一；延迟补偿；宽高比归一；威胁优先级；后坐力分离；死亡释放；帧率无关；软锁定；回正平滑。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
